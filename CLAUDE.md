# Instruksi Claude Code

Sebelum melakukan pekerjaan apa pun, baca PROJECT_MEMORY.md dan AGENTS.md di akar proyek ini, lalu ikuti panduannya.

PROJECT_MEMORY.md adalah satu-satunya sumber status, keputusan, progres, dan serah terima bersama Codex. Jangan membuat memori proyek lain yang menduplikasi atau menggantikan file tersebut.

Periksa berkas aktual, lanjutkan dari langkah berikutnya yang masih relevan, dan perbarui memori sebelum mengakhiri sesi. Gunakan Bahasa Indonesia. Jangan menyatakan halaman telah diaudit atau fitur telah diuji tanpa bukti.

Arahan pengguna 12 Oktober 2026: pada SETIAP perintah baru, baca ulang AGENTS.md bagian "Pemeriksaan versi dan koordinasi wajib untuk semua AI" dan status terbaru PROJECT_MEMORY.md. Wajib memeriksa perubahan lokal, fetch GitHub, membandingkan versi, menghindari berkas sesi aktif lain, serta membaca ulang berkas yang berubah sebelum menulis. Setelah perubahan selesai dan terverifikasi, sinkronkan commit yang siap ke GitHub dan runtime sesuai aturan bersama. Jangan memakai checkout, database, atau build lama tanpa rekonsiliasi. Persetujuan sinkronisasi GitHub sudah diberikan pengguna; pekerjaan AI lain yang belum selesai tidak boleh ikut dipublikasikan tanpa peninjauan.
